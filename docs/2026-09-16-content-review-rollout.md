### 재점검에서 고친 것

1. **출처와 주장의 연결을 좁혔다.** 처음에는 법제처 페이지의 *국내주식* 설명에 있는 기본공제
   250만 원을 해외주식 근거로 기록했다. 그 페이지는 기본공제의 국외자산 적용 여부를 명시하지
   않으므로 확인 범위에서 제외하고 미확인 항목으로 옮겼다.
2. **미검토와 근거 미확정을 코드로 분리했다.** 절·FAQ 단위 `provisional: { reason }` 을 도입해,
   근거가 확정되지 않은 부분은 "확인 전 정보" 문구를 붙여 공개하는 대신 공개에서 보류한다.
3. **검사 우회 지점을 제거했다.** Provisional 색인 검사가 같은 함수로 만든 집합을 자기가 검사하는
   구조였다. 화면·사이트맵이 실제로 부르는 `getIndexableGuides()` 와 규칙 판정을 교차 확인하도록 바꿨다.

## 2. 상태 전환 확인 결과

| 시나리오 | 결과 |
|---|---|
| Verified + 기준 지문 일치 | Verified 유지, 색인 |
| Verified + 기준값 변경 | → Pending Review, 색인 유지 |
| Provisional + 기준값 변경 | → Provisional 유지, 색인 차단 유지 |
| Pending Review + 기준값 변경 | → Pending Review 유지 (승격 없음) |
| 색인 문서가 Provisional 문서를 링크 | 빌드 실패 |

기준값 변경 감지는 빌드로도 확인했다. 한 가이드를 임시로 Verified 로 올려 빌드하면 화면에
"공식 출처 확인" 이 표시되고, `taxRates.ts` 의 값 하나만 바꿔 다시 빌드하면 같은 문서가
"재검토 대상" 으로 바뀐다. (실험은 별도 복사본에서만 했고 저장소 값은 그대로다.)

### 실행하지 못한 검사

**원본 macOS 환경의 프로덕션 빌드 (`npm run build`)** — 이 세션에서 실행 경로가 없었다.

- 작업 셸은 맥 안의 Linux VM이라 macOS 용 `node_modules` 를 쓸 수 없고, Linux 용 swc 다운로드는 차단됨
- 컴퓨터 제어는 터미널을 클릭 전용으로만 허용해 명령을 입력할 수 없음
- 별도 컨테이너는 `fonts.googleapis.com` 이 차단돼 `next/font` 가 실패

폰트만 대체한 복사본 빌드는 성공했지만 **원본 빌드 통과로 볼 수 없다.**
배포 전에 맥에서 `npm run build` 를 직접 1회 실행해야 한다.
