공개 계산기에는 `처음 사용하시나요?` 안내가 각각 한 번만 표시된다. DCA는 자체 3단계 안내를 사용하고, 계산기가 두 개 있는 `/sequence-risk-calculator`도 안내가 한 번만 표시된다. 가이드·정책 페이지와 `/lab`에는 표시하지 않는다. 도움말은 프리렌더 HTML에 포함된다.

## 1차 검증에서 발견해 수정한 내용

- 미국주식 배당 안내를 `주당 연간 배당금` 기준으로 정정하고 잘못된 `연 4회` 예시 제거
- 평가손익·본전 회복·해외주식 세금·목표가 도움말을 실제 입력 필드에 맞게 정정
- 평균단가 2종을 N행 매수 내역 구조에 맞게 설명
- 배당 계산기의 `주가`를 `평균 매수가`로, 손절 계산기에 보유 수량 안내 추가
- 포트폴리오 도움말을 실제 `변동성` 라벨과 통일
- DCA·목표달성·FIRE·순서 위험 계산기의 경로 수 기본값을 `10,000`으로 설정
- 사용자 오류에서 내부 필드명 대신 한글 입력명 표시
- 시뮬레이션 난수 시드를 `결과 재현 번호`로 변경
- 코인 진입 계산기의 종잣돈 의미 `시드`를 `투자 원금`으로 변경
- 성공확률 경고를 목표 입력이 있는 결과에만 포함하도록 정정

## 엔진 버전 정책

현재 엔진 버전은 `1.0.1`이다.

- **patch**: 계산식 호환성을 유지하는 버그 수정, 경고·메타데이터 문구 및 검증 보완
- **minor**: 기존 입력과 결과를 유지하면서 선택 기능이나 가산적 결과 필드 추가
- **major**: 계산 모형, 필수 입력, 기존 결과 의미 또는 타입 호환성을 깨는 변경

이번 변경은 계산식과 입력·결과 타입을 바꾸지 않고 `meta.warnings`의 적용 조건을 바로잡은 수정이므로 `1.0.0`에서 `1.0.1`로 올린다.

## 구조상 주의

`/sequence-risk-calculator`는 `calculatorHelp.ts` 맵을 사용하지 않고 `SorrSimulationCalculator`가 도움말을 한 번 직접 렌더링한다. 이 경로를 맵에 추가하면 두 `CalculatorLayout`과 인라인 안내가 중복될 수 있으므로 구조를 함께 정리한 뒤 변경해야 한다.
