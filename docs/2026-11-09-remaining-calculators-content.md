**보류(사유) — 이번 커밋에 넣지 않은 것**
- 컴포넌트 안내 문구(`emptyMessage`, ‘처음 사용하시나요?’ 도움말)가 필수 입력을 빠뜨린 곳: 청산가(유지증거금률), 레버리지 수익(수수료율), 코인 수익(매수·매도 수수료율), 펀딩비(적용 횟수), 진입(손익비), 미국 배당 도움말 예시(원천징수세율). 계산기 컴포넌트 변경이라 설명 정리 범위 밖 — 메타 설명에는 필수 입력을 적어 두었다.
- `/crypto/profit` 결과 카드의 “실제 순손익” 2회 표시, `/crypto/funding-fee`의 “총 예상 펀딩비”와 “누적 펀딩비” 동일 값, `/overseas-stock-tax-calculator` 실효 세율의 정수 표시(12.83% → “13”), `/goal-probability-calculator` 라벨의 부동소수점 `${targetProbability*100}%` 표시: 컴포넌트 변경 사항으로 별건.
- `CALCULATORS`(허브 카드·sitemap 제목)와 다른 페이지 `related[].title`의 이름(예: “환율 반영 수익 계산기”, “코인 물타기 계산기”, “펀딩비 계산기”)은 바꾸지 않았다. 허브 페이지가 함께 바뀌어 범위를 넘고, URL·sitemap에는 영향이 없다.
- 설정 페이지(withPageMetadata)의 og:title에는 사이트 이름이 붙지 않고 buildMetadata 페이지에는 붙는 기존 불일치는 그대로다(변경 전과 동일한 동작).
- `/overseas-stock-tax-calculator` FAQ “국내주식 매매차익은 현재 비과세”, `/us-stocks/dividend` 금융소득종합과세 안내 등 세법 서술은 이번에 재확인하지 않았다(기존 SourceNote 검토일 기준 유지).
- 공통 보일러플레이트(“본 계산기의 결과는 참고용이며…”)는 Disclaimer 컴포넌트 1곳만 남기고, 더 알아보기 블록 안의 복제본만 제거했다. Disclaimer·SourceNote·결과 카드 안내처럼 역할이 다른 문구는 유지했다.

## 사례의 가정과 검산

- 모든 숫자는 `src/data/stockCalculatorExamples.ts`의 사례 객체(`CALCULATOR_EXAMPLES` 19개 + `CRYPTO_AVERAGE_BASIC`)에서만 가져온다. 기대값은 Python `Fraction`(정확 유리수)과 복리는 `Decimal`(60자리)로 따로 계산했고, 구현 결과를 복사하지 않았다. 복리 두 사례의 정확값 201,340,138.54…·72,022,055.997…은 반올림 경계에서 충분히 떨어져 있어 부동소수점 구현과 같은 정수로 표시된다.
- 가정값: 코인 수익·레버리지 수익의 수수료율 0.05%, 미국주식 환율 사례의 수수료 0원, 배당 사례의 세율 15.4%(국내 배당소득세 기본값)·미국 배당 원천징수 15%·해외주식 기본공제 250만 원은 `taxRates.ts` 상수와 같음을 테스트로 묶었다. 세금·수수료 포함 여부는 각 사례 문장에 적었다.
- 공식 근거가 필요한 새 주장은 추가하지 않았다. 증권거래세 절사 방식은 `stockTransactionTax.ts` 구현과 SourceNote 조건에 이미 있는 내용이다.
