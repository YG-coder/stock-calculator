## 검증 증거와 범위

- 정적 분석, 타입 검사, 전체 회귀 검사, 프로덕션 빌드 통과.
- `npm run build`가 `scripts/check-site-urls.mjs`를 실행한다. 사이트맵 42페이지와 사이트맵 밖 색인 허용 페이지까지 총 42페이지의 canonical·og:url 경로, 자사 origin, OG/Twitter 절대 이미지 주소, 큰 카드, JSON-LD, robots, 실제 이미지 파일 존재를 검사한다.
- 생성 HTML과 대표 상태의 렌더 텍스트에서 camelCase/snake_case 식별자를 검사한다. 소스 AST에서 동적 조사 하드코딩을 검사한다. 프레임워크 내부 오류 문서와 noindex 경로는 색인 대상 검사에서 제외한다.
- 로컬 서버의 사이트맵 대상 42페이지·robots·사이트맵 응답을 확인했다. 대표 공유 이미지는 HTTP 200, image/png, 1200×630이었다. www 퓨니코드 Host 요청도 정본 주소로 308 이동했다.
- 입력·화면 회귀 범위: 통화 선택, 빈칸과 0, 불완전 매수 행, 시뮬레이션 초기화와 늦은 콜백, 화면 문구와 주소 회귀 검사.
- 기존 공식 자료/수기 기대값 검사는 재실행했지만, 이번 작업에서 법령·금융 정책을 새로 확정하거나 모든 상품 조건을 검수하지는 않았다. 테스트 수·커버리지 비율을 정확성 근거로 사용하지 않는다.

## 유지한 조건

가상 경로 수 10,000과 재현 번호의 빈 값→0은 금융금액이 아닌 시뮬레이션 도구 설정으로 유지했다. FIRE의 기존 방어용 이전 결과 표시 판정도 유지하지만, 정상적인 입력 변경에서는 이전 결과를 지운다.
