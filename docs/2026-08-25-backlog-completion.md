### 증권거래세 계산기 신설

경로: `/stock-transaction-tax-calculator`

| 시장 | 증권거래세 | 농어촌특별세 | 합계 |
| --- | ---: | ---: | ---: |
| 코스피 | 0.05% | 0.15% | 0.20% |
| 코스닥 | 0.20% | 0% | 0.20% |
| 코넥스 | 0.10% | 0% | 0.10% |
| K-OTC | 0.20% | 0% | 0.20% |
| 일반 비상장·장외 | 0.35% | 0% | 0.35% |

K-OTC와 일반 비상장·장외를 별도 시장으로 구분했다. 계산기는 매도금액을 과세표준으로 사용하며 양도소득세와 증권사 수수료는 포함하지 않는다.

후속 검증에서 실제 징수 방식에 맞춰 증권거래세와 농어촌특별세를 각 세목별로 원 미만 절사한 뒤 합산하도록 정정했다. 코스피 매도금액 999,999원은 증권거래세 499원과 농어촌특별세 1,499원, 합계 1,998원이다.

공식 근거는 국가법령정보센터의 증권거래세법 시행령 제5조, 농어촌특별세법 제5조이며 최종 검토일과 시행 기준일을 페이지에 표시한다.

## 정책 페이지 확인

운영 주체 `인컴랩`과 문의 이메일 `support@주식계산기.kr`이 운영 사이트의 소개·문의·정책 영역에 표시된다. AdSense 기업 계정에 등록한 법적 사업자 정보와의 최종 일치 여부는 계정 화면에서 운영자가 확인해야 한다. 확인되지 않은 주소나 전화번호는 임의로 추가하지 않았다.

## 외부 확인이 필요한 항목

Search Console은 현재 브라우저가 로그인되지 않아 내부 색인 상태를 확인하지 못했다. 외부에서 확인한 상태는 다음과 같다.

- 기존 페이지는 Google `site:` 검색 결과에 노출됨
- sitemap과 robots.txt는 운영 서버에서 정상 응답
- 신규 증권거래세 계산기는 운영 서버 HTTP 200이며 sitemap에 포함됨

Search Console 로그인 후 신규 URL 검사와 색인 요청 여부만 최종 확인하면 된다.
